# Nepal Mentor 🎓

### A Role-Based Mentor–Mentee Learning Platform

Nepal Mentor is a full-stack web and mobile application designed to connect students (mentees) with mentors for academic guidance and skill development. The platform enables structured interaction through request management, role-based dashboards, and secure authentication.

The system is designed to improve accessibility to mentorship by providing a scalable, user-friendly solution for managing mentor–mentee relationships.

---

## 🚀 Key Features

### 👩‍🎓 Mentee

- Browse mentors based on subject and expertise
- Send and manage mentorship requests
- Track session history and feedback
- Receive updates on request status

### 👨‍🏫 Mentor

- Manage profile and availability
- Accept or reject mentorship requests
- Track assigned mentees and sessions
- Provide ratings and feedback

### 🔐 System Features

- Role-based authentication (Mentor & Mentee)
- Separate dashboards for different user roles
- Request management system (CRUD operations)
- Rating and review system
- Secure data handling

### 💳 Payment Integration

- Integrated **eSewa payment gateway** for transaction handling

## 🏗 System Overview

The application follows a modular full-stack architecture:

- **Frontend** handles user interface and interaction
- **Backend** manages APIs, authentication, and business logic
- **Database** stores user data, requests, and transactions
